FAQ

Shopify Technical SEO questions

Have a different question? Ask me on WhatsApp.

Can you edit robots.txt on Shopify?

Yes, through the robots.txt.liquid template. It’s easy to break things, so I only add rules that solve a specific problem I’ve confirmed in Search Console.

Should Shopify tag pages be indexed?

Usually not. Most tag pages are thin filtered views. The exception is a tag combination that matches real search demand. In that case it’s usually better to create a dedicated collection for it.

Will technical fixes break my theme?

No. All work happens on a duplicate theme first and is tested before it’s published. You can roll back with one click.

Do you work on headless Shopify (Hydrogen)?

Yes, for technical SEO reviews: rendering, routing, canonicals and sitemaps. Large Hydrogen builds are scoped on a case-by-case basis.
