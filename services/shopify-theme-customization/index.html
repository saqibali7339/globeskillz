FAQ

Theme Customization & Liquid questions

Have a different question? Ask me on WhatsApp.

How fast can you fix a Shopify bug?

Small CSS or Liquid fixes are often done the same day. Bigger features are quoted with a fixed timeline before work starts.

Will my customizations survive a theme update?

Code is kept in separate snippets and sections wherever possible, so updates are easier. When a major theme version comes out, I can move everything over for you.

Do you work on paid themes like Impulse, Prestige or Turbo?

Yes, on all popular paid themes and on Dawn and other free Online Store 2.0 themes.

Can you replace an app with custom code?

Often, yes, especially for badges, size charts, simple bundles and FAQ sections. I’ll tell you when an app is actually the better choice.
